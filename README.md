On your SD-card, go to _nds --> TWiLightMenu --> 3dsmenu --> themes
Place the folder in the themes folder
Put the SD-card in your DS and turn it on
Go to the TWLMENU++ GUI settings
Set Curstom Theme to 3DS THPS Theme
Set User Interface to Nintendo 3DS
Set DSi/3DS UI Music to Custom Theme
Close the settings menu and you're good to go!
