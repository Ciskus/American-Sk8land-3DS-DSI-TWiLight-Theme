How to Install:
1. On your SD-card, go to _nds --> TWiLightMenu --> 3dsmenu --> themes.
2. Place the folder in the themes folder.
3. Put the SD-card in your DS and turn it on.
4. Go to the TWLMENU++ GUI settings.
5. Set Curstom Theme to 3DS THPS Theme.
6. Set User Interface to Nintendo 3DS.
7. Set DSi/3DS UI Music to Custom Theme.
8. Close the settings menu and you're good to go!
